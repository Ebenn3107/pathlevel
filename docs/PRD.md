# PathLevel - Product Requirement Document (PRD)

## Product Overview

### Product Name

PathLevel

### Tagline

Track Your Journey. Level Your Growth.

### Product Description

PathLevel is a personal growth dashboard that combines habit tracking, structured learning roadmaps, learning resource management, and gamification into a single platform.

The application helps users build consistency, monitor progress, and stay motivated throughout their learning and self-improvement journey.

---

# Problem Statement

Many learners use multiple disconnected tools for:

* Habit tracking
* Learning roadmaps
* Notes and resources
* Progress monitoring

This fragmentation creates unnecessary complexity and makes it difficult to visualize overall growth.

PathLevel aims to provide a unified system where learning progress and personal development can be tracked together.

---

# Goals

## Primary Goals

* Centralize personal growth tracking
* Improve learning consistency
* Encourage discipline through habit systems
* Increase motivation through gamification
* Visualize learning journeys using roadmap graphs

## Secondary Goals

* Serve as a personal software engineering project
* Learn modern fullstack development
* Build a portfolio-ready application

# Core Features (V1)

## 1. Dashboard

Purpose:
Provide a quick overview of user progress.

Features:

* XP display
* Current level display
* Habit completion summary
* Learning progress summary
* Active roadmap summary

---

## 2. Habit Tracking

Purpose:
Build daily consistency.

Features:

* Create habit
* Edit habit
* Delete habit
* Mark habit as completed
* Daily streak tracking
* Habit statistics

Reward:

* XP gained when habits are completed

---

## 3. Learning Roadmap

Purpose:
Provide structured learning paths.

Features:

* Roadmap graph visualization
* Roadmap nodes
* Progress tracking
* Completion tracking

Initial Roadmaps:

* JavaScript
* TypeScript
* React
* Node.js

---

## 4. Learning Resources

Purpose:
Store references related to roadmap nodes.

Features:

* Add resource
* Edit resource
* Delete resource

Supported Resources:

* Article links
* Documentation links
* GitHub repositories
* Video links

---

## 5. XP & Level System

Purpose:
Increase motivation through gamification.

Features:

* Global XP
* User level
* XP gain history

XP Sources:

* Habit completion
* Roadmap node completion

---

# Out of Scope (Not Included in V1)

The following features are intentionally postponed:

* Mobile application
* Social features
* Friends system
* Public profiles
* Leaderboards
* AI recommendations
* Real-time collaboration
* Achievement badges
* Focus Area XP
* Team workspaces

---

# Success Metrics

V1 will be considered successful if:

* Daily habit tracking works reliably
* Roadmap progress can be tracked
* Resources can be attached to roadmap nodes
* XP and level systems function correctly
* User can consistently use the application as a daily dashboard

---

# Long-Term Vision

PathLevel will evolve into a complete personal growth platform that combines:

* Habit systems
* Learning systems
* Knowledge management
* Roadmap planning
* Gamification

into a single ecosystem.
