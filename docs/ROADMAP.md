# PathLevel - Product Roadmap

## Vision

Build a personal growth platform that combines:

* Habit Tracking
* Learning Roadmaps
* Resource Management
* Progress Analytics
* Gamification

into a single ecosystem.

---

# Development Philosophy

Build progressively.

Each version must be usable before moving to the next version.

Avoid over-engineering.

Focus on delivering working features first.

---

# V1 - Foundation Release

Status:
Planned

Goal:

Create a fully usable personal growth dashboard for daily usage.

Core Features:

* Authentication
* Dashboard
* Habit Tracking
* Learning Sessions
* Learning Resources
* Global XP System
* Statistics & Analytics

Success Criteria:

* Daily usage is possible
* XP system works
* Habits can be tracked consistently
* Resources can be managed
* Dashboard provides useful insights
