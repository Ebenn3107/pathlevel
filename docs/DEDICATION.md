# PathLevel - Dedication

## Why I Built PathLevel

PathLevel was born from a personal challenge.

As a student and lifelong learner, I often found myself using multiple tools to manage different aspects of growth. One application for habits, another for tasks, another for learning resources, and yet another for tracking progress. Over time, this fragmentation made it difficult to see the bigger picture of my personal development.

I wanted a system that could connect everything together.

A place where I could:

* Track daily habits
* Follow structured learning roadmaps
* Organize learning resources
* Monitor long-term progress
* Stay motivated through gamification and leveling systems

PathLevel is my attempt to build that system.

This project is not only a productivity application. It is also a learning journey.

Through PathLevel, I aim to learn and practice:

* JavaScript
* TypeScript
* React
* Node.js
* Database Design
* Software Architecture
* Git and GitHub
* Docker
* Fullstack Development

Every feature built in this project represents a step forward in both personal growth and technical growth.

The long-term vision of PathLevel is to become a platform that helps people learn, build habits, and progress through their own journey with clarity and consistency.

PathLevel is more than a dashboard.

It is a digital representation of continuous improvement.
